# OpenMRS Dependency Vulnerability Report - Starter challenge 

This project is a tool to check for vulnerabilities in the dependencies of OpenMRS modules. It uses the [OWASP Dependency-Check](https://owasp.org/www-project-dependency-check/) tool to scan the dependencies and generate a report of any vulnerabilities found.

# Tech stack used: JavaScript, HTML, Tailwind CSS, Carbon Design system

# Running the module:
* Clone the repo and under root folder, run using: `npx serve .`
